# ESP32 Data Logger

## Goal
Build a robust low-power ESP32 environmental data logger that reads sensors, timestamps measurements and stores them locally without requiring a cloud connection.

## Planned features
- ESP32 firmware and environmental sensor integration
- RTC/date-time support
- microSD CSV logging
- Configurable sampling interval
- Local status display and battery monitoring
- Deep sleep / low-power operation
- Boot, recovery and hardware error handling
- Clear wiring/setup documentation

## Portfolio objective
Demonstrate ESP32, embedded C/C++, sensors, local storage, RTC handling, low-power design and hardware debugging.

## Status
Planning. Hardware-dependent development will begin when components are available.
